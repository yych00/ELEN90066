# WS5 与地面避障完整控制器

使用文件：[KobukiNavigationStateChart_combined.c](KobukiNavigationStateChart_combined.c)。代码中的功能说明、参数和关键判断均有中文注释。

## 接入课程工程

用本文件替换原工程中的 `KobukiNavigationStateChart.c`，或将工程的状态机编译项指向本文件。函数接口与课程接口一致。

工程中只编译一份 `KobukiNavigationStatechart()` 实现。原来的坡道版、避障版和 `full_jzc` 可留作参考，但不要同时加入编译项，否则会出现重复定义。继续使用课程提供的 `KobukiNavigationStateChart.h` 和 `KobukiSensorType.h`。

## 运行流程

1. 按下并松开 B0 启动，平地接近坡道。
2. 最近 8 次分类至少 7 次为上坡后，进入爬坡。
3. 确认坡顶平地后经过坡顶；如果直接遇到下坡，也允许从爬坡直接进入下坡。
4. 已经进入下坡后，最近 8 次分类至少 7 次为平地，才进入最后定距直行。
5. 按正常直行命令覆盖的前进区间累计 200 mm，然后当次输出左右轮零速并锁止。

初始平地和坡顶均不会启动最后的停车距离。没有独立的低速落地确认阶段。

平地使用整体倾角不超过 3° 的规则，同时检查前后和横向倾斜。上坡/下坡阈值为 ±5°；介于判定范围之间或合加速度明显异常的读数不算有效平地票。全部基于原始读数投票，不取平均。

本流程按“一次上坡、一次下坡、下坡后连接终点地面”设计。如果下坡中途存在平坦平台，仅靠加速度计不能判断它是不是最终地面，需要额外路线条件。

## 坡上与地面的检测

- 上坡、坡顶、下坡：关闭 bumper 避障，保留悬崖检测；上、下坡保留 Y 差速纠偏。
- 接近坡道和最后的平地直行：启用三只前方 bumper，执行倒车 120 mm、转开 80°、绕行 300 mm、回正。
- Y 使用最近 5 次中至少 3 次同方向超阈值的规则，下坡纠偏方向与上坡相反。
- 悬崖优先于地面避障：弧线倒车 60 mm，转向 30°。警报仍有效时再次倒车，不会直接输出前进指令。
- 悬崖打断碰撞避障时，取消旧避障动作，保留路线阶段，清空检测窗口后恢复路线。
- 暂停恢复当次也会检查悬崖与地面 bumper。倒车、转向以及暂停不会积累坡度或 Y 检测历史。

## 终点距离与按钮

`FINISH_DISTANCE_MM` 默认 **200 mm**，在源文件顶部修改。也可用编译参数 `-DFINISH_DISTANCE_MM=300` 改为 300 mm。

计距只累计正常路线直行期间的正向里程变化；暂停期间、避障倒车、原地转向、绕行前进和悬崖处理均不计入。避让或暂停前已累计的距离保留，恢复后继续累计。确认平地之前的下坡里程不计入。

到达距离阈值时立即给出零速命令。实际停车位置仍会受状态机调用周期、里程计精度和机械惯性影响，需要实机检查。

- 运行时按 B0：立即暂停；释放后再次按下并释放，恢复原路线与动作。
- 到达终点：保持零速，B0、bumper、悬崖输入均不能重新启动。
- 按 B1：清空路线、动作、投票窗口与终点里程，停车等待新一轮 B0 启动。
- 重置时 B0 已按住：必须先释放，再重新按下并释放，防止意外启动。

## 默认轮速

| 阶段 | 轮速，mm/s |
|---|---:|
| 接近坡道、最后平地直行 | 200 / 200 |
| 上坡直行 | 200 / 200 |
| 上坡纠偏 | 外侧 200，内侧 150 |
| 坡顶 | 150 / 150 |
| 下坡直行 | 100 / 100 |
| 下坡纠偏 | 外侧 100，内侧 75 |
| 地面倒车 | -120 / -120 |
| 地面转向 | 两轮反向，大小 110 |
| 悬崖倒车 | -50 / -80，按方向交换 |
| 悬崖转向 | 两轮反向，大小 80 |
| 完成锁止 | 0 / 0 |

回正按有符号航向误差选择方向，接近目标时减速，误差进入 ±5° 后恢复路线。所有输出最后应用 `WHEEL_SPEED_TRIM`，并限制在调用方的 `maxWheelSpeed` 范围内。

## 离线验证

在本目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run_combined_tests.ps1
```

脚本默认使用本地 `ws6` 课程包中的头文件与 PATH 中的 GCC；也支持 `-Compiler`、`-StatechartInclude`、`-SensorInclude` 指定其他位置。

验证包含 GNU89/C99 严格语法检查，以及 24 个传感器/里程序列。每个序列分别传入真实接口和仿真接口标志，合计 48 次离线运行。包括完整坡道、无平顶坡道、投票容错、坡上忽略碰撞、横向倾斜、Y 纠偏、暂停清空窗口、终点排除避让里程、持续悬崖、回正过头、角度跨圈、终点锁止及 B1 重置。

这些是离线输入验证，未连接真实 Kobuki，也未运行 LabVIEW/CyberSim。回正收敛测试中的 64 ms 周期与 230 mm 轮距仅是测试模型参数，不是当前实机测量结果。
